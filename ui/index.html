多端管理：统一管理本机 Windows、WSL 各发行版中的 DSH 实例。SSH 远程端暂待开发（DSH 目前不能安全地直接暴露到公网）。WSL 端支持启停与连通检测；会话、插件、技能等数据读取仅对接本机 Windows 的 DSH_HOME。

手动添加端

以下配置直接读写当前端 DSH 的 settings.yaml，修改后需重启 DSH 生效。启动器不做统计，仅展示 DSH 原生配额与已用数据。

DSH settings.yaml 编辑器

直接读写 DeepSeek 官方 DSH 的 settings.yaml，修改后需重启 DSH 生效。
保存会覆盖原文件，请确认 YAML 格式正确后再保存。

cordis.patch.yml 编辑器（插件注册层）

直接读写 profile 的 cordis.patch.yml，用于手动调整插件的 insert/disable 配置，修改后需重启 DSH 生效。
保存会覆盖原文件，请确认 YAML 格式正确后再保存。
